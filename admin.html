Paste your deployed Google Apps Script Web App URL to automatically log inquiries to Google Sheets and receive email alerts.

How to Setup Google Sheets & Email Alerts:

  1. Create a new Google Sheet.
  2. In the top menu, go to Extensions > Apps Script.
  3. Clear any default code and paste this script: 
    function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  
  // Headers check (run once or verify sheet headers)
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Date", "Client Name", "Company", "Email", "Phone", "Category", "Quantity", "Message"]);
  }
  
  sheet.appendRow([
    new Date(),
    data.name,
    data.company,
    data.email,
    data.phone,
    data.category,
    data.quantity,
    data.message
  ]);
  
  // Send email alert to shapesuniform@gmail.com
  MailApp.sendEmail({
    to: "shapesuniform@gmail.com",
    subject: "New Shapes Uniform Lead: " + data.company,
    body: "New bulk order request details:\n\n" +
          "Name: " + data.name + "\n" +
          "Company: " + data.company + "\n" +
          "Email: " + data.email + "\n" +
          "Phone: " + data.phone + "\n" +
          "Category: " + data.category + "\n" +
          "Quantity: " + data.quantity + "\n" +
          "Message: " + data.message
  });
  
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}
  4. Click the Deploy button (top right) > New Deployment.
  5. Click the Gear icon > select Web App. Configure:
    • Execute as: Me
    • Who has access: Anyone (necessary for browser requests)
  6. Click Deploy, authorize the permissions, and copy the Web App URL.
  7. Paste the URL in the Webhook input field above and save settings.
